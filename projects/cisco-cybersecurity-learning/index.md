## What Cisco Academy Covers

Cisco's online academy is a free, structured way to build real networking knowledge: IP addressing, routing and switching basics, network security fundamentals, and hands-on configuration practice using Cisco Packet Tracer. It's practical, self-paced study rather than a classroom course, which fits well around the rest of my work.

## Why I'm Doing This Alongside NCFE

Networking fundamentals underpin most of cyber security, so this sits alongside my [NCFE Level 3 Certificate](/projects/ncfe-level-3/) rather than instead of it. Where NCFE covers broader security practice, Cisco Academy gives me more depth on the networking side specifically: how traffic actually moves, and how to secure it.

## Progress So Far

I'm working through the curriculum module by module, using Packet Tracer to build and troubleshoot small simulated networks rather than just reading theory.
