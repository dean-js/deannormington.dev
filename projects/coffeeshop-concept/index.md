## Why I Built This

This concept site was built as one of the small demo company websites from my 100 Days of Code challenge - a chance to practice structuring a full small-business site (home, menu, about, location, contact) rather than a single-purpose app or tool.

## What I Learned

- Structuring a multi-section marketing site with clear navigation
- Responsive layout techniques for menus and image-led sections
- Writing clean, semantic HTML and CSS for a content-first site

## What's Next

Future updates may include a filterable menu, a simple booking or enquiry form, and refined mobile styling.
