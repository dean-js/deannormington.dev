## What This Challenge Is

100 Days of Code is a simple rule: show up and write code every day for 100 days, and keep a record of it. No day is too small to count, a quick fix, a short script, or a full concept site all go in the log. The point isn't to sprint, it's to build a habit I can point to.

## How I'm Approaching It

Rather than treating each day as an isolated exercise, I'm using the challenge to build a small set of concept projects I can actually keep and showcase, like the [Coffeeshop Concept](/projects/coffeeshop-concept/) site. That way the daily practice adds up to something beyond the streak itself: real HTML, CSS, and JavaScript fundamentals, and a growing set of demo work for the portfolio.

## Progress So Far

The tracker on the homepage reflects where I currently am in the challenge. I'll keep this page and that tracker updated as the days add up, along with links to whatever comes out of each stretch of work.

## Why I'm Doing This

Consistency is the whole point. It's an easy, low-pressure way to keep building fundamentals alongside the day-to-day of the e-commerce role, and to make sure I'm still shipping small things regularly rather than only learning in theory.
